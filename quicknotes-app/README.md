# Quick Notes App

---

## About

Quick Notes is a simple browser-based app for writing and managing notes. It lets you add notes with a category, search by note text or category, and save your notes in the browser so they’re available when you return.

---

## Features

- Add notes with a category.
- See each note’s creation date and time.
- Search notes by their text or category.
- Delete individual notes.
- Validate notes so they can’t be empty or longer than 200 characters.
- Save notes and drafts in browser local storage.
- Switch between light and dark themes.
- See character and word counts while writing.

---

## Run Locally

1. Download or clone this project.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a browser.

Alternatively, if Python is installed, open a terminal in the `quicknotes-app` folder and run:

```powershell
py -m http.server 8000
```
